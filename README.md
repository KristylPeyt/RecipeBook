# 📖 Recipe Book Android App

Recipe Book is a simple Android application developed using **Kotlin** and **XML** in Android Studio. It allows users to add and manage sweet and savory recipes in an organized list using RecyclerView.

## ✨ Features

- **Recipe List** – Displays recipes grouped by flavor (Sweet and Savory).
- **Add Sweet Recipes** – Add new sweet recipes with a title and description.
- **Add Savory Recipes** – Add new savory recipes with a title and description.
- **View Recipe Details** – Tap a recipe to view its description in a dialog.
- **Swipe to Delete** – Remove recipes from the list by swiping them aside.

## 🛠️ Built With

- Kotlin
- XML
- Android Studio
- RecyclerView
- AlertDialog
- ItemTouchHelper

## 🚀 Getting Started

1. Clone this repository.
2. Open the project in Android Studio.
3. Wait for Gradle synchronization to finish.
4. Run the application on an Android emulator or physical device.

## 🎯 Purpose

This project was created as part of an Android development learning activity to practice using RecyclerView, custom adapters, ViewHolders, click listeners, and swipe gestures.
